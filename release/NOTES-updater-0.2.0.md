# Revamped Updater 0.2.0 — Character rune transition

Install this APK before updating the game to 1.3.0. It uses the existing signer and the same DroidDeck Files connection.

The rune transition deletes this game's old progress and Continue save **once**. The native action announces **Reset saves & install**. It locates the selected game's own Steam prefix, records the exact native/companion save files before changing them, and resumes an interrupted reset without broad directory deletion. Other games, unrelated files, mod settings and Wine registry remain.

The installed transition marker keeps later or repeated updates from deleting new progress. A game-folder-only grant asks for the broader DroidDeck/Steam-library folder before deployment. No root, all-files permission, Shizuku or USB is needed for normal use.

Native isolated fixture verification covers deletion scope, an interruption after the first real deletion, recovery, the visible warning, preserved settings/other-game files and later/repeated update preservation. Public delivery verification checks the exact APK, package/version, source commit and persistent signing certificate.
