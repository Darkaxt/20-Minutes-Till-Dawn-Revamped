# Stillness and compact native menus

- Stillness restricts movement only while shooting. Release fire or reload to move normally;100% bullet damage/size and the extra projectile remain. Existing supported checkpoints rebuild the corrected stat channel without a save reset.
- Twelve centered metrics: duplicate Max HP and Magazine rows are removed; native hearts/ammo remain at top left.
- Native upgrade panels place the path beside the description on the left and aligned Benefits/Penalties icon rows in a dedicated right column. Miniatures use native hexagons and the current character portrait where the known special ability directly benefits. Actual signed stat consumers determine each row.
- Locked campaign buttons use native padlocks. Descriptions/unlock conditions are concise; attempt-status and redundant unlocked-tier text are removed.
- Clear-count crowns sit inside applicable mode buttons and update with selected Darkness/Challenge tier. Quickplay uses fixed difficulty0; Endless/Custom have none. Historical totals were not stored, so counts begin with this update and persist in the existing companion journal.
- The native Metrics label omits F2; the shortcut still works.

Verified in windowless native Windows scenes at square,4:3 and16:9, with controller/pointer/F2, actual acquisitions, firing/release/reload, current and1.1.6 checkpoint replay, signed icon rows, actual victory presentation and fresh-process clear-count persistence. Controlled clock/quota/acquisition operands are test fixtures, not natural full-run balance results. [Contracts and evidence](../docs/PLAYTEST-FIXES.md).

The existing Android updater remains compatible. Only the production DLL changes in the614-target payload;613 other hashes and prepared assets are unchanged. Deployment remains user-controlled; no phone or live Steam deployment is included.
