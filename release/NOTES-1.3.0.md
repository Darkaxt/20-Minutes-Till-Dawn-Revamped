# 1.3.0 — Character runes and arena-boss rewards

Runes now belong to each character and are earned through arena-boss lotteries. Credit purchases, hold-to-buy, prices and column prerequisites are removed. Press earned runes to toggle them independently, including multiple choices in the same row; each rune still has five ranks. Existing Windows ranks and selections seed character profiles once.

Forest awards 1/3/6/10 draws at Darkness 0/4/8/12, distributed across the corresponding rune rows. Temple uses Darkness+4; Pumpkin Patch uses +2. Standard splits half to each arena boss, with the odd draw going to the second. Quickplay's single arena boss receives its full allotment. Endless repeats for every boss pair; Challenge awards once, while Custom remains excluded.

One popup reveals each lottery slot in turn, then burns capped runes into XP gems inside it. A discarded tier-1 rune is half a character level; tier-2 is one, tier-3 is one and a half, and tier-4 is two. The normal upgrade/evolution flow remains. Continue preserves saved results, reveals and XP delivery without rerolls or duplicate grants. New permanent ranks improve subsequent runs.

Wild Magic restarts Curse and Smite chains at its existing rank-scaled death chance. Elemental Barrage counts electrical stun and wind disorientation alongside Burn/Freeze. Dedication counts distinct offensive summon families, treating paired actors as one and excluding defensive Seismic Ward.

**DroidDeck users: install Revamped Updater 0.2.0 first.** The APK resets this game's old progress and Continue save once for this transition. Its action explicitly announces the reset; other games, settings and registry remain. An installed epoch prevents repeat/later updates from wiping new progress. Windows installation preserves existing earned rune power. No live installation is changed by publishing these packages.
