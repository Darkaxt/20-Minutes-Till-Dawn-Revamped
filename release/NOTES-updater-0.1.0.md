# Revamped Updater 0.1.0

Update an existing Revamped installation inside DroidDeck directly from GitHub.

- Connect DroidDeck once through Android Files. The updater automatically finds the game through Steam's library catalogue and remembers the folder.
- See installed and available game versions, release notes, download verification and installation status.
- Install compatible owned-code updates while preserving saves, progression, settings, original files and prepared artwork.
- Resume interrupted deployments using the recorded verified payload and originals.
- Native Android interface using the chosen utility layout and Revamped colors. No GitHub login, root, Shizuku, USB or background service is needed for ordinary use.

Requires an already prepared Windows game/mod inside DroidDeck. Asset or loader changes requiring Windows preparation are reported before installation. This APK is the updater, not the game or a native Android port.

Install `Revamped-Updater-0.1.0.apk`. See [connection and build instructions](https://github.com/Darkaxt/20-Minutes-Till-Dawn-Revamped/tree/main/android-updater).
