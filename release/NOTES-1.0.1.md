# 1.0.1 release notes

Windows release. DroidDeck delivery is tracked separately and does not gate this release.

Android 8.6 gameplay is reconstructed for the supported Windows build, preserving the recorded source mechanics and quirks while using native Windows controls. No independent balance patch or mobile commerce is imported.

- Charge Cannon and its three evolutions; Gale and Bulwark characters and exclusive upgrades.
- Source-linked combat, perk, rune, enemy/map, Challenge/Endless and semantic Continue behavior, including the selected Android-state rebuild for old checkpoints.
- Thirty thematic encounter unlock gates and persistent notices. Credits fund runes; rune ranks compound in price by 20%, use same-column prerequisites and allow multiple enabled choices per row.
- Native Custom menus, obtained-content limits and mode defaults; credits only, with unlocks and achievements disabled.
- Transparent icon-led attributes/collected-skill HUD, effective/base/bonus values, tiers/counts, optional reversible recolours, pixel-art MAINTAINED BY DARKAXT credit and removed Emberpath promotion.

The Windows build passes installed copied-player roster/input, native progression/settings/continuation workflows, package integrity and actual Steam-directory owned install/rollback while preserving original files and the real profile. Coverage uses isolated windowless Windows players with controlled test preconditions, including selected legacy saves; it is not an exhaustive natural playthrough or phone acceptance.

Installation requires the supported owned Windows Steam build 12679152 and exact Android 8.6/1093 APKM specified in INSTALL.md. Game artwork is prepared locally and is not bundled in the public archive. See INSTALL.md for upgrade/uninstall and docs/ANOMALIES.md for retained source behavior and evidence limits.
