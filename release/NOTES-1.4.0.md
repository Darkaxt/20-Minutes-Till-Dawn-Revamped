# 1.4.0 — Appearance collection

- Add Appearance beside Runes in character and weapon selection, with controller and pointer navigation, an opaque panel, previews and paged icons that fit square and widescreen displays.
- Select and remember each character's skin and wings, and each weapon's skin and bullet colour. Original appearance and no wings remain available.
- Include the Android 8.7 catalog: six character skins, 85 weapon skins, 49 wings and seven bullet-colour choices. Seven colours are freely selectable; skins and wings are earned by victories.
- Each successful non-Custom run grants one unowned character skin or shared wing and one unowned skin for the played weapon, while eligible rewards remain. No prices, paid draws, passes or seasonal expiry. Reopening the same run cannot duplicate its rewards.
- Carry source animation, character portraits, crow/spirit/black-hole artwork, wings and the Broom projectile appearance through the real render/pool paths. Continue keeps its saved run appearance even if the menu selection changes later.
- Preserve gameplay stats, hitboxes, skill counts, current progression, settings and existing Continue checkpoints. No additional save reset.
- Correct a reproduced consecutive journal/checkpoint publication failure and keep cosmetic asset updates independent of title-scene UI lifetimes.

New artwork must be prepared locally using the existing Android 8.6/1093 gameplay input and the Android 8.7/1105 appearance input. Updater 0.2.0 correctly requests Windows preparation for this changed asset set. The public download includes code and extraction recipes, not game artwork. Saint Rosa's separate gameplay integration remains outside this appearance release.
