# Display and Isaac-style HUD

- Native Zoom out setting:0/25/50/75/100% extra world view. HUD/menu scale stays normal.
- Resolution works in fullscreen; chosen native16:9 resolution is retained.
- Metrics:Off, Little and Extended, via Options or F2. Little shows calculated values with pastel comparisons; Extended includes base/bonus. Off leaves selected skills visible.
- Character traits first, summons next, weapons last. Right-hand acquired skill icons/tiers/counts fit4:3 and survive Continue.
- Original timer at top center, with credits earned this run below it using the native reward calculation.
- Natural unlock sentences; activate a locked character/weapon to inspect recorded progress. Rules, ownership and wallet are unchanged.
- Challenge counters share native HUD scaling and fit below the timer/credits.

Verified in a windowless copied Windows player at4:3/16:9, with native controller/pointer/F2, actual acquisitions, Continue, long skill lists and legacy-setting migration. Fullscreen requests are intercepted only in validation to avoid desktop display changes. No phone-runtime claim; deployment remains user-controlled.

The614-target updater contract changes only the mod DLL. Existing prepared artwork/loader files and the Android updater APK remain compatible.
